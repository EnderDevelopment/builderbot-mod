# BuilderBot Mod

AI-powered building assistant for Minecraft

## Features

- Spawn and control a BuilderBot entity
- Build structures from predefined commands or text prompts
- Supports both survival and creative modes
- Includes pathfinding and basic AI behaviors

## Requirements

- Minecraft 1.21.11
- Fabric Loader 0.14.0 or later
- Fabric API

## Installation

1. Download the mod JAR file
2. Place it in your `mods` folder
3. Launch Minecraft with Fabric

## Usage

### Commands

| Command | Description |
|---------|-------------|
| `/builder spawn` | Spawns a BuilderBot at your location |
| `/builder build <structure>` | Builds a predefined structure |
| `/builder build prompt <description>` | Builds from a text description |
| `/builder stop` | Stops the current building process |
| `/builder resume` | Resumes the building process |
| `/builder despawn` | Despawns the BuilderBot |

### Permissions

All commands are available to all players by default.

## Configuration

The mod currently doesn't have a configuration file, but future versions may include settings for:

- BuilderBot health and speed
- Building speed and range
- Default structures
